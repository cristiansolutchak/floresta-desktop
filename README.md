# Floresta GUI

A desktop app for running and managing a [Floresta](https://github.com/getfloresta/Floresta) Bitcoin node without the terminal. It finds or installs `florestad`, guides setup, starts and stops the node, shows sync, peers and logs, and follows Floresta's **watch-only** wallet.

> **Status: v0.0.1 pre-release.** Tested on macOS (Apple Silicon) and Linux (arm64 and x64, Debian 12) against real `florestad` v0.9.1 nodes. Windows build scripts are ready but not yet tested on Windows. Mainnet sync works but can be slow or stall: Floresta needs peers that serve Utreexo proofs, and few are online. See [CHANGELOG.md](CHANGELOG.md).

## What it does

- Supervises `florestad` as a child process and talks to its local JSON-RPC server, bound to `127.0.0.1` only (the RPC has no authentication).
- Shows sync progress honestly: blocks this node verified itself are kept apart from the Utreexo snapshot it starts from.
- Finds and adds peers that serve Utreexo proofs, which Floresta 0.9.1 needs and often lacks.
- Watch-only wallet: balances, addresses and activity from public descriptors. It never asks for, stores or sends private keys or seed phrases, and it cannot sign or send. Use Sparrow or Electrum connected to the node's Electrum server (`tcp://127.0.0.1:50001` on mainnet) for that.

## Installing

1. Install the app: open the `.dmg` and drag Floresta to Applications (macOS), or `sudo apt install ./floresta-gui_<version>_<arch>.deb` (Linux; the `.tar.gz` also works: run `bundle/floresta_gui`).
2. Open it. The first-launch screen installs `florestad` v0.9.1 automatically from signed builds of the official release ([floresta-gui-release](https://github.com/cristiansolutchak/floresta-gui-release)), after checking its signature, checksum and version.

**macOS:** the app is not yet signed with an Apple Developer ID, so Gatekeeper blocks the first launch. Right-click the app, choose **Open**, then **Open** again.

**Linux:** built and tested in Debian 12 (needs glibc 2.34 or newer). Other distributions are untested.

**Using your own florestad:** build it from source (the Installation screen shows these steps and the prerequisites for your system):

```bash
git clone https://github.com/getfloresta/Floresta.git && cd Floresta && git checkout v0.9.1
cargo install --path ./bin/florestad --locked
```

The app finds it on your `PATH`, in `~/.cargo/bin`, `/opt/homebrew/bin` or `/usr/local/bin`; otherwise choose it in Installation.

## Troubleshooting

- **"Port … is in use"**: another Floresta or Bitcoin Core node is running. Stop it, or change the RPC port in Settings.
- **Sync shows "Stalled" or "Waiting for Utreexo peers"**: the node has no peer that serves proofs. The app keeps looking and adds the ones it can verify; this depends on the network, not on your setup.
- **The node stopped unexpectedly**: Logs shows its last output. With "Write a log file" on, the full log is `debug.log` in the data folder.
- **Asking for help**: Help → Copy Diagnostics, or Logs → Export Diagnostics. Diagnostics contain no wallet data, and extended public keys are redacted from the log.

Data lives in `~/.floresta/` (one folder per network) unless you choose another folder. Removing the app never deletes it.

## Develop

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d macos
```

Opt-in tests against real nodes: `tool/regtest/bootstrap.sh` prepares a local regtest cluster, then `flutter test test/integration`. On Linux (Debian 12 container): `tool/test_linux_in_container.sh arm64|x64`. On Windows: `tool\windows\test_windows.ps1`.

Release builds: `tool/build_app.sh production` then `tool/package_macos.sh` (macOS) or `tool/build_linux_in_container.sh` (Linux); `tool\windows\build_app.ps1 production` then `tool\windows\package_windows.ps1` (Windows). florestad builds: `tool/release/build_florestad_artifact.sh`, `tool/release/build_florestad_linux_in_container.sh`, `tool\windows\build_florestad_artifact.ps1`. `integration_test/` holds full-app runs (`flutter test integration_test/<file> -d macos`). The app icon is generated by `swift tool/brand/render_app_icon.swift`.
